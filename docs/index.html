Language cheat sheet
Program shape
  • begin program: … end program
  • Declarations: begin VarDecl: (x, int); end VarDecl
  • Types: int, char; arrays (a[10], int);
Values
  • Integers carry their base: (1010, 2), (17, 8), (42, 10)
  • Chars: 'a', strings: "x = @"
  • Identifiers: lowercase, digits, at most one _
Statements (each ends with ;)
  • x := e, +=, -=, *=, /=, %=
  • if (c) begin … end else begin … end
  • while (c) do begin … end
  • for i := e to e inc e do begin … end
  • print("v = @", v), scan("@", v)
Operators
  • Arithmetic: + - * / %
  • Relational: = <> < > <= >=
  • Comments: // line, /* block */
